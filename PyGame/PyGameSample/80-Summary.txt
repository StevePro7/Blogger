<u>Summary</u><br />
To summarize, we have now completed to port Simpsons Trivia video game from C#/.NET to Python using PyGame.  This exercise provides great foundation to further explore <a href="https://steveproxna.blogspot.com/2024/09/openai-farma-cheat-sheet.html">Farama Foundation Gymnasium</a> project in which <a href="https://gymnasium.farama.org/environments/classic_control">Classic Control</a>, <a href="https://gymnasium.farama.org/environments/toy_text">ToyText</a> and <a href="https://gymnasium.farama.org/environments/box2d">Box2D</a> environments are all implemented using PyGame.  Experience gained here should provide solid grounding for any future work in  Reinforcement Learning research space!
