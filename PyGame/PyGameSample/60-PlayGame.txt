<b>PLAY</b><br />
In PyCharm hit F5 to run Python code or Terminal enter <b>uv run SimpsonsTrivia.py</b> to play Simpsons Trivia!

<b>CONFIG</b><br />
Update <a href="https://github.com/SteveProXNA/PythonSetup/blob/master/PyGameSample/SimpsonsTrivia/Assets/Data/Config/GlobalConfig.toml">GlobalConfig.toml</a> configuration settings like set CheatMode or FullScreen to true vary the game play!
<br />
<table width="99%" border="1">
<tr><td>&nbsp;&nbsp;<strong>GlobalConfig.toml</strong></td></tr>
<tr><td>
<pre style="font-size: 12px;">
&nbsp;&nbsp;FPS=50
&nbsp;&nbsp;ScreenType=&quot;Splash&quot;
&nbsp;&nbsp;DifficultyType=&quot;Easy&quot;
&nbsp;&nbsp;SoundEnable=true
&nbsp;&nbsp;CheatMode=true
&nbsp;&nbsp;RandomQuestions=true
&nbsp;&nbsp;RandomAnswers=true
&nbsp;&nbsp;Fullscreen=true
