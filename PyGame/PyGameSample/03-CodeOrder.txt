02.
AnGame.py
Build game infrastructure
Intermediary between Game bootrap [and service registry]
which delegates game init, load, update + draw game loop to actual ST game implementation code

i.e.
AnGame controller - delegates all work to MyGame

    def Run(self):
        self.Initialize()
        self.LoadContent()

        while self.running:
            MyGame.Manager.EventManager.ProcessEvents()
            if MyGame.Manager.EventManager.QuitRequested:
                self.Exit()

            deltaTime: int = MyGame.Manager.ClockManager.Update()
            self.Update(deltaTime)
            self.Draw()
