Why I need it for PyCharm navigation
PyCharm cannot statically infer dynamically created manager attributes, so a .pyi type stub is needed to provide type information for code navigation, autocompletion, and static analysis.


Why the .pyi fixes it

A .pyi file is called a type stub.

It doesn't contain implementation—it contains type information.
