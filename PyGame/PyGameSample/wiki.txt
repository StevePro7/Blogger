<u>Simpsons Trivia</u><br />
<a href="https://steveproxna.blogspot.com/2018/05/simpsons-trivia-code-complete.html">Simpsons Trivia</a> is a retro fan-made quiz game built for the 2018 SMS Power! Coding Competition originally targeting the Sega <a href="https://www.smspower.org/Homebrew/SimpsonsTrivia-SMS">Master System</a>.  The game was ported to the <a href="https://steveproxna.blogspot.com/2023/06/sega-console-game-port.html">Sega Genesis</a>, <a href="https://steveproxna.blogspot.com/2018/08/simpsons-trivia-windows-port.html">Windows</a>, <a href="https://steveproxna.blogspot.com/2018/09/simpsons-trivia-android-port.html">Android</a> and <a href="https://steveproxna.blogspot.com/2018/11/simpsons-trivia-ios-port.html">iOS</a>.

<b>Dissection</b><br />
Before jumping into the full code dissection let's document some of the support folders with their functions:
<br /><br />
<u><a href="https://github.com/SteveProXNA/PythonSetup/tree/master/PyGameSample/SimpsonsTrivia/Game/Static">Static</a></u><br />
Includes globally loaded game resource assets and colors definitions.  Constants store core configuration with enumerations defining all strongly-typed categories as Python enums and globalize has UI text information.
<br /><br />
<u><a href="https://github.com/SteveProXNA/PythonSetup/tree/master/PyGameSample/SimpsonsTrivia/Game/Objects">Objects</a></u><br />
Includes game data models to represent configuration, questions and text elements to rendered on-screen.
<br /><br />
<u><a href="https://github.com/SteveProXNA/PythonSetup/tree/master/PyGameSample/SimpsonsTrivia/Game/Inputs">Inputs</a></u><br />
Includes low-level input layer for game engine to convert raw PyGame input into cleaner game input APIs.
<br /><br />

<u><a href="https://github.com/SteveProXNA/PythonSetup/blob/master/PyGameSample/SimpsonsTrivia/Game/AnGame.py">AnGame.py</a></u><br />
Builds game infrastructure and acts as an intermediary between the game bootstrap and the service registry which delegates game init, load, update and draw game loop methods to actual game implementation code.
<br />
<table width="99%" border="1">
<tr><td>&nbsp;&nbsp;<strong>AnGame.py</strong></td></tr>
<tr><td>
<pre style="font-size: 12px;">
&nbsp;&nbsp;class AnGame:
&nbsp;&nbsp;    def __init__(self):
&nbsp;&nbsp;        self.running: bool = True
&nbsp;&nbsp;        build_game()
&nbsp;&nbsp;
&nbsp;&nbsp;    def Run(self):
&nbsp;&nbsp;        self.Initialize()
&nbsp;&nbsp;        self.LoadContent()
&nbsp;&nbsp;
&nbsp;&nbsp;        while self.running:
&nbsp;&nbsp;            MyGame.Manager.EventManager.ProcessEvents()
&nbsp;&nbsp;            if MyGame.Manager.EventManager.QuitRequested:
&nbsp;&nbsp;                self.Exit()
&nbsp;&nbsp;
&nbsp;&nbsp;            deltaTime: int = MyGame.Manager.ClockManager.Update()
&nbsp;&nbsp;            self.Update(deltaTime)
&nbsp;&nbsp;            self.Draw()
</pre>
</td></tr>
</table>
