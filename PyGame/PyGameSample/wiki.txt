<u>Simpsons Trivia</u><br />
<a href="https://steveproxna.blogspot.com/2018/05/simpsons-trivia-code-complete.html">Simpsons Trivia</a> is a retro fan-made quiz game built for the 2018 SMS Power! Coding Competition originally targeting the Sega <a href="https://www.smspower.org/Homebrew/SimpsonsTrivia-SMS">Master System</a>.  The game was ported to the <a href="https://steveproxna.blogspot.com/2023/06/sega-console-game-port.html">Sega Genesis</a>, <a href="https://steveproxna.blogspot.com/2018/08/simpsons-trivia-windows-port.html">Windows</a>, <a href="https://steveproxna.blogspot.com/2018/09/simpsons-trivia-android-port.html">Android</a> and <a href="https://steveproxna.blogspot.com/2018/11/simpsons-trivia-ios-port.html">iOS</a>.  
<br /><br />

<b>Dissection</b><br />
Before jumping into the full code dissection let's document some of the support folders with their functions:
<br /><br />
<u><a href="https://github.com/SteveProXNA/PythonSetup/tree/master/PyGameSample/SimpsonsTrivia/Game/Static">Static</a></u><br />
Includes globally loaded game resource assets and colors definitions.  Constants store core configuration with enumerations defining all strongly-typed categories as Python enums and globalize has UI text information.
<br /><br />
<u><a href="https://github.com/SteveProXNA/PythonSetup/tree/master/PyGameSample/SimpsonsTrivia/Game/Objects">Objects</a></u><br />
Includes game data models to represent configuration, questions and text elements to rendered on-screen.
<br /><br />
<u><a href="https://github.com/SteveProXNA/PythonSetup/tree/master/PyGameSample/SimpsonsTrivia/Game/Inputs">Inputs</a></u><br />
Includes low-level input layer for game engine to convert raw PyGame input into cleaner game input APIs.

&nbsp;&nbsp;        if seed is None:

<u><a href="https://github.com/SteveProXNA/PythonSetup/blob/master/PyGameSample/SimpsonsTrivia/Game/Managers/EventManager.py">EventManager</a></u><br />
Event polling game system collecting Pygame events each frame and here is used mainly to track quit game.
<br />
<table width="99%" border="1">
<tr><td>&nbsp;&nbsp;<strong>EventManager.py</strong></td></tr>
<tr><td>
<pre style="font-size: 12px;">
&nbsp;&nbsp;class EventManager:
&nbsp;&nbsp;    def __init__(self):
&nbsp;&nbsp;        self.QuitRequested = False
&nbsp;&nbsp;        self.Events = []
&nbsp;&nbsp;
&nbsp;&nbsp;    def ProcessEvents(self):
&nbsp;&nbsp;        self.Events.clear()
&nbsp;&nbsp;        for event in pygame.event.get():
&nbsp;&nbsp;            self.Events.append(event)
&nbsp;&nbsp;            if event.type == pygame.QUIT:
&nbsp;&nbsp;                self.QuitRequested = True
&nbsp;&nbsp;            if event.type == pygame.KEYDOWN and event.key == pygame.K_ESCAPE:
&nbsp;&nbsp;                self.QuitRequested = True
</pre>
</td></tr>
</table>

<tr><td>&nbsp;&nbsp;<strong>ScreenManager.py</strong></td></tr>
<tr><td>
<pre style="font-size: 12px;">
&nbsp;&nbsp;class ScreenManager:
&nbsp;&nbsp;    def Initialize(self):
&nbsp;&nbsp;        self._import_all_screens()
&nbsp;&nbsp;        screen_classes = self._build_screen_map()
&nbsp;&nbsp;        self.screens: dict[ScreenType, BaseScreen] = {
&nbsp;&nbsp;            st: cls()
&nbsp;&nbsp;            for st, cls in screen_classes.items()
&nbsp;&nbsp;        }
&nbsp;&nbsp;        for screen in self.screens.values():
&nbsp;&nbsp;            screen.Initialize()
&nbsp;&nbsp;
&nbsp;&nbsp;    def Update(self, deltaTime: int):
&nbsp;&nbsp;        if self.currScreen != self.nextScreen:
&nbsp;&nbsp;            self.currScreen = self.nextScreen
&nbsp;&nbsp;            self.screens[self.currScreen].LoadContent()
&nbsp;&nbsp;        tempScreen = self.screens[self.currScreen].Update(deltaTime)
&nbsp;&nbsp;        if tempScreen:
&nbsp;&nbsp;            self.nextScreen = tempScreen
&nbsp;&nbsp;
&nbsp;&nbsp;    def Draw(self):
&nbsp;&nbsp;        MyGame.Manager.DisplayManager.Clear(self.color)
&nbsp;&nbsp;        self.screens[self.currScreen].Draw()
&nbsp;&nbsp;        MyGame.Manager.DisplayManager.Present(self.color)
&nbsp;&nbsp;
&nbsp;&nbsp;    def _import_all_screens(self):
&nbsp;&nbsp;        for _, module_name, _ in pkgutil.iter_modules(Screens.__path__):
&nbsp;&nbsp;            if module_name == BaseScreen.__name__:
&nbsp;&nbsp;                continue
&nbsp;&nbsp;            path_name: str = f&quot;{const.GAME_DIRECTORY}.{ENGINE_SCREENS}.{module_name}&quot;
&nbsp;&nbsp;            importlib.import_module(path_name)
&nbsp;&nbsp;
&nbsp;&nbsp;    def _build_screen_map(self) -&gt; dict[ScreenType, type[BaseScreen]]:
&nbsp;&nbsp;        screen_map: dict[ScreenType, type[BaseScreen]] = {}
&nbsp;&nbsp;        for screen_type in ScreenType:
&nbsp;&nbsp;            class_name = f&quot;{screen_type.name}{ENGINE_SCREEN}&quot;
&nbsp;&nbsp;            path_name: str = f&quot;{const.GAME_DIRECTORY}.{ENGINE_SCREENS}.{class_name}&quot;
&nbsp;&nbsp;            module = importlib.import_module(path_name)
&nbsp;&nbsp;            cls = getattr(module, class_name)
&nbsp;&nbsp;            screen_map[screen_type] = cls
&nbsp;&nbsp;        return screen_map
