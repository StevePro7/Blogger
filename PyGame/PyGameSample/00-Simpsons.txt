<u>Simpsons Trivia</u><br />
<a href="https://steveproxna.blogspot.com/2018/05/simpsons-trivia-code-complete.html">Simpsons Trivia</a> is a retro fan-made quiz game built for the 2018 SMS Power! Coding Competition originally targeting the Sega <a href="https://www.smspower.org/Homebrew/SimpsonsTrivia-SMS">Master System</a>.  The game was ported to the <a href="https://steveproxna.blogspot.com/2023/06/sega-console-game-port.html">Sega Genesis</a>, <a href="https://steveproxna.blogspot.com/2018/08/simpsons-trivia-windows-port.html">Windows</a>, <a href="https://steveproxna.blogspot.com/2018/09/simpsons-trivia-android-port.html">Android</a> and <a href="https://steveproxna.blogspot.com/2018/11/simpsons-trivia-ios-port.html">iOS</a>.
