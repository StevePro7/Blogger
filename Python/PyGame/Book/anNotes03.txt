Chp 6	Object References, Mutability, and Recycling
CODE
Bootstrap.py
module = importlib.import_module(path_name)
manager_class = getattr(module, module_name)
ServiceRegistry.register(
    manager_class.__name__,
    manager_class()
)
Bootstrap
dynamically creates each manager and registers its reference in the shared mutable ServiceRegistry
this way multiple parts of the application can access each manager reference via-> ServiceRegistry
