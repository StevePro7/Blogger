Chp 10	Design Patterns with First-Class Functions
Not officially a GoF design pattern but this application does implement MyGame.Manager as a Service Locator
e.g.
MyGame accesses all game managers via the Manager facade which delegates to the ServiceRegistry
- provides one consistent access point for application services
- avoids passing every manager through every method as required
# allows to code in any scrren or manager to access any game manager at anytime via this syntax
MyGame.Manager.QuestionManager.SetQuizLength(...)

NB:
Manager components are not strictly enforced Singletons
they are single registered service instances managed through a Service Locator
