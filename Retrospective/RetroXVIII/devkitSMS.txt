I would use this sequence:

    Instructions: Create .github/copilot-instructions.md describing the C coding conventions, devkitSMS APIs, Z80/SDCC constraints, memory limitations, and build commands.

    Custom agents: Create .github/agents/ agents specialising in game logic, graphics and sprites, audio, and code review.

    Skills: Create .github/skills/ workflows for adding a sprite, implementing controller input, debugging a build failure, and testing a generated ROM.

    Validate: Have Copilot implement a small feature, run make, inspect compiler errors, and verify the resulting ROM in an emulator.

For the official technical reference on implementing skills, use 
GitHub Docs: Adding agent skills for GitHub Copilot
